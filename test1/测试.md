# 快手短剧自动筛查 — 实施方案

## 一、目标

在安卓端快手App中自动执行以下流程：

1. 识别搜索框 → 输入短剧名 → 点击搜索
2. 下拉刷新搜索结果（提升鲁棒性）
3. 点击第一个视频 → 截图
4. 找到视频作者 → 进入作者主页
5. 识别快手号（作者ID）
6. 点击返回 → 点击下一个视频 → 重复至最后一个

## 二、技术选型

### 方案：AScript MCP + UI层级树

| 方案 | 描述 | ID识别精度 |
|---|---|---|
| **AScript MCP + UI层级树** | 无线连接手机，直接读Android界面真实文本节点 | **100%** |
| Claude Sonnet/Opus 视觉理解 | 截图 + 模型视觉识别 | 高（但依赖模型能力） |
| OCR（Tesseract/PaddleOCR） | 图像文字识别 | 中（易被图标干扰） |

**选定方案的原因：**
- UI层级树读取的是应用内部真实文本数据（XML中的TextView节点），不受界面图标干扰
- OCR会将复制图标识别为"0"（实际验证："快手号：yingbin111"被OCR误识别为"yingbin1110"）
- AScript MCP支持WiFi无线连接，不需要USB数据线

### 对比验证记录

```
截图真实内容:  [快手号：yingbin111] [📋复制图标]

OCR 识别结果:   yingbin1110   ❌  (复制图标被误识别为数字0)
UI层级树读取:   yingbin111   ✅  (读TextView原始文本)
```

## 三、手机连接方案：AScript MCP（已实现）

### 连接链路

```
手机 (AScript App) → WiFi局域网 → AScript MCP服务 → Claude Code/PC
```

### 实际配置

手机：**HONOR BVL-AN00** (Android 16)
AScript运行模式：**无障碍模式**
MCP服务：`python -m ascript_mcp.local`
连接方式：WiFi局域网（IP: 172.16.1.139:9096）

### MCP提供的主要工具

| 工具 | 功能 |
|---|---|
| `scan_devices` | 扫描局域网设备 |
| `connect_device` | 连接设备 |
| `screen_capture` | 截图（返回PNG到PC） |
| `dump_ui_tree` | 获取UI控件层级树（JSON） |
| `deploy_and_run` | 部署Python脚本到手机运行 |
| `get_device_status` | 设备状态信息 |

## 四、实现方式

采用**混合架构**：PC端做分析和决策，手机端执行操作。

```
PC端 (Python):
  1. dump_ui_tree → 分析UI树 → 找到目标控件坐标
  2. deploy_and_run → 发送action.click(x,y)到手机
  
手机端 (AScript):
  执行点击、滑动、输入等操作
```

### 核心脚本

| 文件 | 说明 |
|---|---|
| `kuaishou_scanner.py` | 原始uiautomator2方案（待ADB环境） |
| `ascript_connect.py` | AScript MCP连接测试 |
| `ascript_screenshot.py` | 截图+UI树获取 |
| `ascript_kwai_scan.py` | **短剧筛查主脚本（已测试通过）** |

### 快手号提取策略

在作者主页遍历UI树，搜索含"快手号"文本的节点，正则提取冒号后的内容。100%精确，不受图标干扰。

## 五、完整流程

```
for 短剧 in 短剧列表:
    回到快手主页
    点击搜索按钮(thanos_home_top_search)
    输入短剧名
    点击搜索/确认
    下拉刷新(提升鲁棒性)
    点击第一个视频封面
    截图保存
    找作者名(@xxx或user_name控件)
    点击进入作者主页
    遍历UI树 → 找"快手号"文本节点 → 提取ID
    返回主页
```

- 建议在手机亮屏、快手在前台的状态下运行
